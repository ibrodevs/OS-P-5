## Цель работы

Реализовать и сравнить основные алгоритмы планирования CPU, вычислить ключевые метрики, исследовать влияние кванта Round Robin и показать проблему голодания и механизм aging.

## Что реализовано

- FCFS;
- SJF;
- SRTF;
- вытесняющее Priority-планирование;
- Priority + aging;
- Round Robin с настраиваемым квантом;
- расчёт waiting time, turnaround, response time, CPU utilization и context switches;
- анализ `q = 1..10` для Round Robin;
- SVG-график зависимости метрик от кванта;
- unit-тесты контрольных случаев.

## Запуск

```bash
python3 sched.py --algo fcfs set1.txt
python3 sched.py --algo srtf set1.txt --gantt
python3 sched.py --algo rr --quantum 3 set1.txt
python3 sched.py --algo priority --aging-interval 2 set1.txt --gantt
```

## Контрольный результат

Для `set1` получено:

| Алгоритм | Среднее ожидание | Средний turnaround |
|---|---:|---:|
| SRTF | 6.50 | 13.00 |
| RR, q=3 | 13.50 | 20.00 |
| FCFS | 8.75 | 15.25 |

## Ключевой вывод

Разные алгоритмы оптимизируют разные свойства. SRTF хорошо уменьшает среднее ожидание, Round Robin обеспечивает справедливое разделение CPU, но маленький квант резко увеличивает число переключений контекста. Aging позволяет уменьшить риск starvation у процессов с низким приоритетом.
